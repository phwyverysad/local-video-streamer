# 🎬 Local Video Streamer & Instant Share

เว็บแอปพลิเคชันสำหรับส่งคลิปวิดีโอขนาดใหญ่ (1 GB – 50 GB+) หรือคลิปขนาดยาวให้เพื่อนเปิดดูได้ทันทีจากเครื่องของคุณ **โดยไม่ต้องอัปโหลดขึ้นคลาวด์** พร้อมปุ่มย่อลิงก์สั้นสุดผ่าน **da.gd** และระบบตัดสิทธิ์ลิงก์ทันทีเมื่อลบวิดีโอ

---

## ✨ จุดเด่นของระบบ

1. **ไม่ใช้ Cloud Storage 100%**:
   - วิดีโออยู่ในเครื่องคอมพิวเตอร์ของคุณเท่านั้น สตรีมส่งข้อมูลตรงให้เพื่อนผ่านท่อสัญญาณปลอดภัย (Secure Tunnel)
2. **สตรีมมิ่งลื่นไหลทันใจ (HTTP 206 Byte-Range)**:
   - เพื่อนไม่ต้องรอโหลดทั้งไฟล์ 10GB จนเสร็จ กดปุ๊บเริ่มเล่นได้ใน 1-2 วินาที และเลื่อนข้ามเวลา (seek) ได้ทันที
3. **ปุ่มย่อลิงก์ da.gd**:
   - กดปุ่ม **"ย่อลิงก์ (da.gd)"** เพียงคลิกเดียว ระบบจะแปลงลิงก์ยาวเป็นลิงก์สั้นจิ๋ว เช่น `https://da.gd/vVid9` คัดลอกส่งในแชทให้เพื่อนได้สะดวก
4. **ตัดสิทธิ์ลิงก์ทันทีเมื่อลบ (Instant Revocation)**:
   - เมื่อกดปุ่ม **"ลบวิดีโอ"** จากหน้าแดชบอร์ด ลิงก์ที่ส่งให้เพื่อนจะกลายเป็นหน้าแจ้งเตือนว่า *"วิดีโอนี้ไม่สามารถรับชมได้แล้ว"* ทันที
   - หากปิดโปรแกรมหรือปิดเครื่อง ลิงก์ทั้งหมดจะดับลงทันที ปลอดภัย ไม่ทิ้งข้อมูลค้างบนอินเทอร์เน็ต
5. **ดีไซน์สะอาดตา (Clean & Light Theme)**:
   - โทนสีขาว-ฟ้าอ่อน พาสเทล เรียบง่าย สบายตา ไม่มีโฆษณา ไม่รกรุงรัง

## 🚀 วิธีเปิดใช้งาน

### วิธีที่ 1: ดับเบิลคลิกไฟล์ (ง่ายที่สุด)
ดับเบิลคลิกที่ไฟล์ **`start.bat`** ในโฟลเดอร์โปรเจกต์ ระบบจะรันเซิร์ฟเวอร์และเปิดหน้าต่างเบราว์เซอร์ให้อัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / PowerShell
```bash
# 1. ติดตั้ง Dependencies (ทำครั้งแรกครั้งเดียว)
npm install

# 2. เริ่มต้นโปรแกรม
npm start
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

## 🧪 การรันแบบทดสอบ (Automated & E2E Browser Tests)

โปรเจกต์นี้มาพร้อมชุดทดสอบครบ 34 รายการ รวมถึงการรันเบราว์เซอร์จริง (Headless Chrome) ทดสอบการคลิกปุ่ม, อัปโหลด, ย่อลิงก์ da.gd, เปิดเล่นคลิป และการเพิกถอนสิทธิ์:

```bash
npm test
```

ผลลัพธ์การทดสอบ:
- `test/registry.test.js`: การลงทะเบียนไฟล์, จัดการ Token, การลบ
- `test/stream.test.js`: การสตรีมมิ่งแบบ HTTP 206 Range requests
- `test/shortener.test.js`: การย่อลิงก์ผ่าน da.gd API
- `test/api.test.js`: การทำงานของ REST API ครบทุก Endpoint
- `test/e2e-browser.test.js`: การทดสอบการใช้งานจริงบนเบราว์เซอร์แบบ End-to-End
